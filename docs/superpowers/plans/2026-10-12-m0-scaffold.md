# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A repository where `task setup && task doctor && task check` is green, the config schema is locked, and the
spec pages are committed.

**Architecture:** Single uv project with the spec's dependency list; `airlie.yaml` validated by pydantic; `task doctor`
as pure checks over an injected probe; Taskfile as the only interface.

**Tech Stack:** Python 3.12, uv, go-task, pydantic v2, typer, rich, pytest, ruff, mypy.

**Spec:** `docs/wiki/build-spec/01_system_architecture_and_hardware_spec.md` §1 (memory budget, wired limit), §3
(dependencies); `docs/superpowers/specs/2026-10-12-airlie-design.md`.

## Global Constraints
- Python `>=3.12`; dependencies from spec 01 §3 with floors raised to current releases.
- `iogpu.wired_limit_mb=106496`; peak allocation must stay under it (spec 01 §1).
- Unknown config keys are errors. Every config error names its key path.
- No pip, no venv activation in any instruction: `task <name>` only.

## Review Focus
1. Memory projection must fail, not warn, when over the wired limit (spec 01 §1) — `test_memory_projection_over_limit_is_fail`.
2. A metadata-only HF snapshot (no `*.safetensors`) must count as missing — `RealProbe.model_snapshot_dir` (live check in M1).
3. A role pointing at a non-preloaded model must still validate (lazy load is a registry feature) — `test_role_may_use_non_preloaded_model`.
4. `airlie.local.yaml` must not be able to introduce unknown keys silently — covered by `test_unknown_key_is_rejected_to_catch_typos` (merge happens before validation).
5. `task setup` on a machine without `vllm-mlx` wheels for the platform must fail loudly at `uv sync`, not at first run — verified by running `task setup` on the Mac.
