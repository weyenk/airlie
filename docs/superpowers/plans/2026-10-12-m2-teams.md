# M2 Team Orchestrator, Tools, Scheduler Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `task run --k 1` on `evals/tasks/lang_detect.yaml` produces code that passes the hidden tests, with every
step traced, through the spec's orchestrator shape (AutoGen team, EdgeAgent HAL + slot scheduling, sandboxed tools).

**Architecture:** `ParallelAgentTeamOrchestrator` (spec 04 §3 names) spawns K `TeamOrchestrator`s. Each team is a
ReAct agent (AutoGen `AssistantAgent` by default, a native loop as fallback) with sandboxed repo tools in its own
git worktree. Every step yields `(u_t, o_t)` to a `StepObserver` seam (M3 plugs LTS in there). The scheduler owns
`HALSpeculativeScheduler` (verbatim) and per-engine slots; a team inside a tool call holds no slot
(`SUSPENDED_TOOL_STALL`).

**Tech Stack:** autogen-agentchat 0.7, autogen-ext[openai], mcp, asyncio, git worktrees.

**Spec:** `docs/wiki/build-spec/04_…` §1 (HAL), §2 (yield protocol), §3 (orchestrator blueprint); `01_…` §2, §4.

## Global Constraints
- Team model reached only through the engine's OpenAI endpoint (AutoGen's `OpenAIChatCompletionClient` → vllm-mlx).
- Tools never leave the team worktree; secret-looking files are refused; shell calls are timeboxed and output-capped.
- `HALSpeculativeScheduler(L_total=16, L_min=1, gamma=0.3, tau=1.5)`, `A_i(0)=4.0` exactly as spec 04 §1.
- Agent states are exactly `ACTIVE` and `SUSPENDED_TOOL_STALL`.

## Review Focus
1. `../` and symlink escapes from the worktree are refused — `test_fs_rejects_escape`.
2. A tool that hangs is killed at `shell_timeout_s` with a clear observation — `test_shell_timeout`.
3. A team that loops on the same tool call is stopped — `test_native_team_repeated_action_stops`.
4. Slot accounting never exceeds `max_active` and a suspended team frees its slot — `test_slots_released_on_tool_call`.
5. AutoGen events map to one `StepRecord` per tool call with `u_t` = call and `o_t` = result — live test.
