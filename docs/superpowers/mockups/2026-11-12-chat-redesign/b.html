B. Rail and panel

Favours screen width and phone parity. A narrow icon rail carries the repository avatar and the sections (chats, board, workflows, metrics, admin). Beside it a list panel slides out with the repository's chats and the plain chats. The header carries one status chip that opens a popover with the VM, engine, context, memory and branch.

  • Move: rail for where you are, panel for which chat; the panel can be closed to give the thread the whole width.
  • Detail: status lives in a popover from the chip; tool rows open a hover card on desktop and a bottom sheet on a phone.
  • Phone: the rail turns into a bottom tab bar, the panel into a slide-over; the layout and the names stay the same.
